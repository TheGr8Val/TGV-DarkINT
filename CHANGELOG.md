# Changelog

All notable changes to this project are documented here.
Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Versioning: [SemVer](https://semver.org/).

## [0.2.0] - 2026-10-02

### Added
- Module M5, "Your First Time on Tor": setup options (Tor Browser, Tails, Whonix, VPN + Tor), do/don't rules, a 7-step first session (DuckDuckGo, Ahmia, hidden wikis and onion directories), legal and ethics notes, quiz.
- Two more final-quiz questions.
- Colourful terminal UI via `rich` (purple/pink theme), emoji, score meter. `--plain` and automatic plain output when piped.

### Changed
- `rich` is now a dependency.

## [0.1.0] - 2026-10-02

### Added
- Initial public release.
