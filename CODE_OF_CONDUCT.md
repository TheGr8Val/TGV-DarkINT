# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep feedback about the work and not the person, and no harassment
of any kind. Maintainers may remove comments, commits or contributors that violate this.

Report conduct concerns privately via a GitHub security advisory contact or by messaging
[@TheGr8Val](https://github.com/TheGr8Val) on GitHub.
