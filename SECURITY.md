# Security Policy

## Supported versions

Only the latest release on `main` receives fixes.

## Reporting a vulnerability

Please report privately through GitHub: **Security tab > Report a vulnerability** on
[https://github.com/TheGr8Val/TGV-DarkINT](https://github.com/TheGr8Val/TGV-DarkINT/security/advisories/new). Do not open a public issue.

Include what you found, how to reproduce it, and the impact. You can expect an acknowledgement within 7 days.

## Scope

TGV-DarkINT ships only synthetic, public-knowledge training content and makes no network connections.
Content issues (for example an example log line that contains a real IP, credential or victim detail) are treated as security reports.
